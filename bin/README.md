# Outils Dolby Vision (facultatif)

Utilisés seulement par `dv.py` (chaîne Dolby Vision expérimentale, désactivée par défaut). Déposez ici les binaires Linux x86_64 :

- `dovi_tool` : https://github.com/quietvoid/dovi_tool/releases (testé : 2.3.4)
- `hdr10plus_tool` : https://github.com/quietvoid/hdr10plus_tool/releases (testé : 1.7.2)

```bash
chmod +x bin/dovi_tool bin/hdr10plus_tool
```
